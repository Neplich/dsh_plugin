# @neplich/dsh-annotations

[English](README.md) · 中文版

一个 dsh Web GUI 插件：在历史助手回复中框选一段文字，将其作为待发送注释附加到当前输入框。注释会随下一条消息一起作为附加上下文发送——你仍然需要自己输入真正的指令。

## 功能

- **框选标注**：在已完成的助手消息中拖选文字，选区附近出现浮动「添加到会话」胶囊按钮（优先出现在上方，空间不足时翻到下方）。
- **持续高亮**：被标注的文字在原消息中保持高亮；高亮能扛过 React 重渲染，注释被删除或发送后同步消失。
- **输入框胶囊**：输入栏显示「N 条注释」胶囊（标准 Pill 造型、注释蓝）。悬停、点击或键盘聚焦胶囊都能打开详情浮层；胶囊内的 × 清除全部注释。
- **详情浮层**：每条注释一行——编号、所选文本（保留换行、长内容限高滚动）、单条删除 ×。悬停某行时原消息中的对应高亮加强；点击该行滚动定位到原文（自动展开折叠的祖先）。
- **随消息发送**：发送时每条注释的原文直接进入消息内容（空行分隔）并成为对话的一部分；发送成功自动清空待发送注释，失败则保留。
- **选区校验**：只能标注单条已完成的 assistant 消息——流式内容、推理（思考）区、工具卡片等其他界面区域、与已有注释重叠的选区均不可标注。
- **中英文界面**：所有文案随 dsh 界面语言切换（含数量表达）。

## 安装

```sh
dsh plugin --profile <name> add @neplich/dsh-annotations
```

使用 `dsh --profile <name>` 启动并打开 Web GUI。

## 配置

无——插件没有可配置项。

## 模型体验

- 注释是**用户消息内容**：发送时每条注释原文会被拼到你的消息前面（空行分隔），模型看到的正是你引用的内容加上你的指令。模型可见内容不依赖界面语言。
- 注释本身不会触发模型请求：输入框为空时发送按钮保持禁用。

## 已知限制与后续工作

- **仅运行时状态**：注释只存在于浏览器会话内——刷新页面或重载插件即清空。持久化（并从日志恢复高亮）留待后续。
- **依赖内置 DOM 结构**：选区锚定依赖内置聊天流的 `data-chat-flow-kind` / `data-chat-anchor-key` 行标记以及 `[data-streaming]` / `[data-variant="think"]` 标记；harness 标记结构变更时可能需要同步更新。
- **Prompt 包装**：发送依赖为存在注释的会话安装的 `session.prompt` 包装（harness 目前没有发送拦截扩展点用于附加上下文）；插件卸载时会还原。
- **高亮仅是展示**：高亮只存在于 DOM（从不进入会话日志）；若重渲染把消息结构改得超出已存路径，该注释会失去高亮（浮层中仍可见）。
